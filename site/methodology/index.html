QuotaWatch methodology

QuotaWatch is an independent tracker. It is not affiliated with any vendor.

  • Every value links to a vendor page (pricing page, docs, or help center), with an exact quote and the date it was checked.
  • Confidence labels: official (vendor page), reported (press or staff post), observed (seen on a live page, change date unknown).
  • Automatic snapshots of each source page run every 6 hours. A change in the text flags a human review before any entry is published.
  • Prices are in USD, before tax, unless noted. Limits are copied as vendors state them. We don't invent absolute numbers where the vendor publishes none.
  • No affiliate links. Sponsors are labeled and never affect the data.
